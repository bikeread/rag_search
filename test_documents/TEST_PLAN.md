# RAG测试文档集合规划

## 📁 测试文档分类

### 1. PDF文档测试集
- `technical_manual.pdf` - 技术手册，含图表和代码示例
- `research_paper.pdf` - 学术论文，含引用和公式
- `scanned_document.pdf` - 扫描版文档，测试OCR能力
- `chinese_report.pdf` - 中文报告，测试中文处理
- `mixed_language.pdf` - 中英文混合文档

### 2. Word文档测试集
- `contract_template.docx` - 合同模板，含表格和条款
- `meeting_minutes.docx` - 会议纪要，含批注
- `technical_spec.docx` - 技术规范文档
- `training_material.doc` - 培训材料，旧格式

### 3. Excel数据测试集
- `financial_report.xlsx` - 财务报表，多Sheet
- `product_catalog.csv` - 产品目录，结构化数据
- `survey_results.xlsx` - 调查结果，含图表
- `kpi_metrics.xlsx` - KPI指标表，数值分析

### 4. 代码文档测试集
- `api_documentation.md` - API文档，Markdown格式
- `python_script.py` - Python代码，含详细注释
- `react_component.jsx` - React组件，前端代码
- `database_schema.sql` - 数据库架构，SQL脚本
- `notebook_analysis.ipynb` - Jupyter笔记本

### 5. HTML网页测试集
- `blog_article.html` - 博客文章，典型网页结构
- `documentation_page.html` - 文档页面，技术内容
- `news_article.html` - 新闻文章，含广告噪音

## 📊 评估指标

### 文档处理质量
- **文本提取率**: 提取文本/原始文本
- **结构保持度**: 保持的结构元素/总结构元素
- **处理时间**: 处理耗时/文档大小
- **错误率**: 错误数/总处理数

### 查询效果质量
- **准确性**: 正确答案/总查询数
- **相关性**: 相关内容/返回内容
- **完整性**: 答案要素/预期要素
- **响应时间**: 平均响应时间
